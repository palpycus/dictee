# Dictée mélodique

Entraînement à la dictée musicale, utilisable sur iPad : https://palpycus.github.io/dictee/

- 370 dictées originales générées (37 niveaux × 10), suivant une progression classique :
  secondes et rondes → blanches, noires, silences → 3/4, 2/4, anacrouse → tierces, gamme →
  liaisons, croches → tonalités majeures et mineures, clé de fa, 6/8, triolets, doubles-croches,
  clé d'ut, 9/8, 12/8, modulations, chromatisme. L'exercice n° N est toujours la même mélodie.
- Déroulement : accord de tonique + première note, puis chaque groupe de 1 à 4 mesures (au choix)
  joué 1 à 5 fois avec une pause pour écrire, puis la dictée entière. La partition reste cachée
  jusqu'au bouton « Réviser ».
- Son de piano (abcjs + soundfont), notation ABC visible à la révision.
- Import de vos propres dictées au format ABC (conservées dans le navigateur).

Fichier unique `index.html`, aucune compilation.
